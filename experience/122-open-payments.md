## Context
[Open Payments](https://openpayments.io) provides a PSD2-compliant platform that lets FinTech companies, e-commerce businesses and other financial actors integrate with European banks through a single API.

From late 2019 to mid-2020 I worked as a fullstack developer on the Customer Portal, where clients onboard, configure access and manage their integrations. The portal was a React single-page application on an ASP.NET Core API, integrated with Dynamics CRM and several Azure services.

## Work
- Built the customer onboarding page (React, TypeScript, Redux) and the ASP.NET Core API behind it
- Integrated the portal with Dynamics CRM and Azure Functions
- Made the functional and integration tests run with less manual setup, which sped up deployments
- Contributed to the CI/CD workflows in Azure DevOps
