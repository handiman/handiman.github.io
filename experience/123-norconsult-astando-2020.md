## Context
My relationship with Norconsult Astando goes back to 2008–2009, when I worked with them as a consultant from Avega Group AB. Nearly a decade later they saw on [LinkedIn](https://www.linkedin.com/in/prettygoodprogrammer) that I had started freelancing and asked if I was available. I came back in 2018 to automate their deployments, and again in 2020 for fullstack development on their older systems.

Norconsult Astando develops GIS-based solutions for municipalities and infrastructure organisations. The systems I worked on were built on ASP.NET Core, ASP.NET Web API and WCF services, with frontend components in JavaScript/TypeScript and KnockoutJS. Deployments ran through TeamCity and Octopus Deploy.

## 2018 — DevOps & backend
### Problem
Deployments for the IsyRoad project were manual, took around 45 minutes per application instance and often went wrong.

### Approach
#### Automation & DevOps
- Introduced automated deployment pipelines using Octopus Deploy
- Integrated TeamCity build steps with the deployment workflow
- Standardised configuration and environment handling
#### Backend development
- Worked on ASP.NET Web API and .NET Core services
- Worked with NHibernate and WCF-based integrations

### Results
- Deployment time went from about 45 minutes to about 5 minutes per instance
- Virtually no deployment-related errors afterwards
- Automated deployment was then rolled out to Isy Map and Isy Case as well

## 2020 — Fullstack development on older systems
- Implemented new features in ASP.NET Core and ASP.NET Web Forms applications
- Improved structure and testability in the existing code
- Built new UI functionality in TypeScript, JavaScript and KnockoutJS
- Extended the deployment automation in Octopus Deploy and TeamCity
