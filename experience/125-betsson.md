## Context
From 2021 to 2025 I worked as a Senior Software Engineer in Betsson Group's Player Rewards & Gamification value stream. The team built and maintained event-sourced gamification systems used in real time across many brands and markets, under high load and strict regulation.

Examples of projects: Tournaments, Loyalty Points, Levels & Achievements.

## Work
### Architecture
- Applied CQRS, Domain-Driven Design, Event Modeling and Event Sourcing
- Introduced [.NET Aspire](https://learn.microsoft.com/en-us/dotnet/aspire/) to simplify developing and testing the distributed applications
- Built proofs of concept for the actor pattern with Microsoft Orleans
- Worked closely with the Enterprise Architect and Engineering Manager on architectural and regulatory requirements
### Backend development
- Built and maintained services with C#, .NET 5–9 and ASP.NET Core
- Built Blazor-based back-office tools
- Designed the PostgreSQL data model for the Levels application
### Automation
- Maintained and improved the CI/CD pipelines in GitHub Actions and Octopus Deploy
- Containerized the Levels application with Docker
### System integration
- Optimized the Kafka message processing in the Tournaments application
- Designed and maintained REST APIs and legacy WCF integrations
### Team
- Mentored junior developers through knowledge-sharing sessions and pair programming
- Took part in technical interviews and candidate assessments
- Gave architectural and implementation guidance to team members

## Results
- Nearly 1000% higher Kafka message throughput in the Tournaments application

## Consultant, then employee
My four years at Betsson — first as a consultant for roughly two years, then as an employee for another two — were an exception to my usual freelancing. I stayed because I enjoyed the company and the colleagues, and left only because I eventually missed the freedom and variety of consulting.
