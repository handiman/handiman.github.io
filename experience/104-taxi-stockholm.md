## Context
While at Qbranch I worked with Taxi Stockholm on moving their intranet and public website from Spirello to EPiServer 4. The new site also had to talk to their Unix-based booking system over a proprietary binary protocol that wasn't documented outside the company.

## Work
### EPiServer migration
- Migrated the intranet and public website from Spirello to EPiServer 4
- Rebuilt templates, content structures and editorial workflows
- ASP.NET, C# and SQL Server
### Booking system integration
- Integrated the site with the Unix booking system using low-level socket programming in .NET
- Implemented the protocol from sparse specifications: byte arrays, offsets and custom message formats
