## How I work

Most of my assignments have been in finance, insurance and online gaming — places where the backend has to be right, not just fast. I work closely with the people who own the problem, look for the pragmatic solution, and write code that's easy to read, test and change.

I lean on agile practices, test-driven development and SOLID design. Tests are written as executable specifications where it makes sense, and I automate the path to production early — with tools like GitHub Actions and Octopus Deploy — so that shipping stays boring.

## What I do

- **Backend development** in .NET and C#, from REST APIs to data layers
- **System integration** across REST, GraphQL, message queues and the occasional legacy system
- **Automation & DevOps**: CI/CD pipelines, scripting and infrastructure as code
- **Architecture**: structuring new projects, untangling old ones, codebase reviews
