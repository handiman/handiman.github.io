Meet UIaaS — Useless Information as a Service. Inspired by Kittens-as-a-Service, it's a fully documented API that returns information you didn't need and can't use. Swagger docs and everything, because if you're going to be useless, you might as well be professionally useless about it.

There's a "usefulness" column in the database. By design, it's only ever allowed to be zero or negative.

There's also a "beg for money" button. No further comment.

The actual point, buried under the bit: from idea to a live, documented API in about an afternoon, with Claude Code. Semantic CV took weeks by comparison. The AI makes the typing fast, not the engineering.
